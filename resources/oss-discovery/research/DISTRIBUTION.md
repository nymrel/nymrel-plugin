# Source-preview distribution packet

This is a draft for the existing product/content and publication owners. It
does not send a message, publish a campaign, or claim completed user validation.

## Intended first audience and first value

Developers and technical support staff who already have an MCP configuration
and a failed-run log. The first useful action is to produce a readable local
report that separates supplied clues from an unknown cause. No live service or
credential is needed for the included synthetic example.

## Suggested source-preview wording

> Nymrel MCP Preflight is an experimental offline configuration/log triage tool.
> It produces a readable report without starting an MCP server or installing
> its packages. It omits raw input values from the report and preserves unknown
> causes. We are testing whether it helps with a narrow setup-troubleshooting
> task compared with current tools. Source, examples, limits, and tests are
> included under the MIT license.

Link the actual reviewed source/archive when delivering this wording. The
containing pull request provides the exact revision and current check results.

## Demonstration sequence

1. Show the synthetic fixture and identify it as synthetic.
2. Run the documented offline CLI and open the resulting report.
3. Explain one useful next-evidence step and show that raw input values are
   omitted.
4. Show the ambiguous/no-signal case, preserving an unverified result.
5. State the incumbent baseline and the human comparison still to be run.

A written sequence is not a recorded demonstration. No recorded demo is claimed.

## Claims and measurement

Supported claims must be bound to actual final-source test/review receipts.
Do not claim a diagnosed or fixed upstream bug, a secure/ready connection,
comprehensive secret detection, faster human diagnosis, universal host support,
Directory approval, registry publication, or actual adoption from fixture tests.

Measure consented first useful reports, correctly understood next actions,
paired diagnosis observations, repeated useful cases, outside contributions,
and compatibility/support outcomes. Leave current values unknown. Do not embed
telemetry or start collection as a side effect of this source package.

Publication uses the existing owner process. No new scheduler, social-delivery
route, paid acquisition, unsolicited external recruitment, or account is created.
