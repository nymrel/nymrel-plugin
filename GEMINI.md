# Nymrel public tools

Use the four Nymrel public tools for relevant requests: website audits, domain
suggestions, carry-distance gap analysis, and short-video transcript checks.
They require no Nymrel account or API key. Ask for the actual URL, concept,
measured distances, or transcript if the request does not supply it.

Report the measured evidence and limitations from the result. Domain availability
must be confirmed with a registrar before purchase. Website checks do not certify
legal compliance or guarantee rankings. Golf carry numbers are supplied by the
user. Clip scores measure text signals and do not predict views or virality.

These tools do not purchase domains, modify websites, publish posts, or send
messages. Never claim those actions happened.

The shared server also advertises seven optional Nymrel Remote read tools. This
extension explicitly includes only the four public utilities. Remote access
requires a separate caller-authorized OAuth connection with devices:read and
tools:read; never request or embed a shared bearer token for public-tool use.

Support: https://nymrel.com/support
